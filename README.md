# 🚀 Sistema SoftTech

Sistema completo de gerenciamento com PHP e MySQL.

## 📋 Sobre

- ✅ Login e cadastro de usuários
- ✅ Painel administrativo
- ✅ Sistema de parceiros
- ✅ Trabalhe conosco (upload de currículos)
- ✅ Design responsivo

## 🛠️ Tecnologias

- PHP 7.4+
- MySQL 5.7+
- HTML5, CSS3, JavaScript

## 🚀 Como Usar

1. Instale o XAMPP
2. Copie para: `C:\xampp\htdocs\softtech\`
3. Crie o banco `softtech_db` no phpMyAdmin
4. Acesse: `http://localhost/softtech/`
